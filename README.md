# Faucets & Valves — WooCommerce theme

قالب فروشگاه عمدهٔ شیرآلات و اتصالات، فارسی و راست‌به‌چپ، برای ووکامرس.

- صفحهٔ نخست: خانهٔ سه‌بعدی سفید که هر اتاقش یک دسته است؛ با کلیک، اتاق رنگی می‌شود و شیرهایش برچسب می‌گیرند. در صفحهٔ شیرهای صنعتی، مدل سه‌بعدیِ شیر باز و بسته می‌شود.
- سبد خرید به شکل مخزن آب، پیش‌فاکتور و فاکتور با تاریخ شمسی، کارت به کارت با بارگذاری رسید، سفارش سریع با کد کالا.
- بدون صفحه‌ساز؛ همهٔ فونت‌ها و کتابخانه‌ها محلی (بدون CDN).

## نصب
این مخزن را در `wp-content/themes/faucets-valves` قرار دهید (یا فایل zip آن را از نمایش › پوسته‌ها بارگذاری کنید) و فعال کنید.
راهنمای کامل تنظیمات در `readme.txt` است.

## ساخت دوبارهٔ صحنهٔ سه‌بعدی
منبع در `src/scene` است و خروجی `assets/js/scene/home.js`. راهنما: `src/README.md`.

## نیازمندی‌ها
WordPress 6.4+، WooCommerce 8+، PHP 7.4+.
